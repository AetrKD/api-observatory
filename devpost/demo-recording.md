## Recording operations

- Choose the specific behavior you want to demonstrate. Core flow available: repository -> call list -> source evidence -> live GET response.
- Keep personal email, account settings, credentials, unrelated windows and private repository names outside the recorded area. Record the relevant app content or crop the account header.
- Use a public example repository and no API key for the sample GET response.
- Show the repository identifier, an actual discovered call, source function/file/line and its code link.
- Show the optional API origin and JSON Accept selection, then the actual HTTP code, duration and JSON preview.
- Show a skipped or unresolved call if explaining the supported boundary.
- Use English UI for the recording if useful. Write your own narration or translated captions.
- Review the finished recording for visible secrets and make sure it fits the current form's duration/format constraints.
- Upload the finished video and verify its link without a signed-in account.
